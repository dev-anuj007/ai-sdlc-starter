# Project AI-SDLC Documentation Artifacts

This directory stores verifiable artifacts generated during each phase of the AI Software Development Life Cycle:

- **`docs/prd/`**: Product Requirements Documents (`PRD-<feature>.md`) generated by `@pm` using [`ai-sdlc/templates/PRD_TEMPLATE.md`](../ai-sdlc/templates/PRD_TEMPLATE.md).
- **`docs/adr/`**: Architecture Decision Records (`ADR-<number>-<title>.md`) generated by `@architect` using [`ai-sdlc/templates/ADR_TEMPLATE.md`](../ai-sdlc/templates/ADR_TEMPLATE.md).
- **`docs/specs/`**: Technical Implementation Specs & Task Checklists (`SPEC-<feature>.md`) generated by `@architect` or `@dev` using [`ai-sdlc/templates/SPEC_TEMPLATE.md`](../ai-sdlc/templates/SPEC_TEMPLATE.md).
- **`docs/reviews/`**: QA & Security Audit Reports (`REVIEW-<feature>.md`) generated by `@qa` and `@security` using [`ai-sdlc/templates/REVIEW_CHECKLIST.md`](../ai-sdlc/templates/REVIEW_CHECKLIST.md).
